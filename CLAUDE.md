# Working in this repo

See [CONTRIBUTING.md](CONTRIBUTING.md) for branches, commits and code style, and [README.md](README.md) for where to
change what.

When a step doesn't need my input, keep going. Put status notes in the same message as your next action.

Stop and ask only when you can't continue without me, or before anything destructive or public: deleting data,
force-pushing, pushing to `main` (it deploys the live site), or changing anything outside this repo.

Done means `npm run test:all` passes and the changed pages are checked in the browser pane (`d5-site` in
`.claude/launch.json`) at 1440, 768 and 390px with a clean console.

End every long run with three headings: Blocked on me, Changed, Found.
